## Objetivo

Agregar un ítem nuevo al sidebar llamado **Inventario**, visible **solo para el rol `admin`**, ubicado **inmediatamente debajo de Rendición de Gastos**.

En esta tarea el ítem queda como **placeholder**, con exactamente el mismo comportamiento que tiene hoy Rendición de Gastos (no navega a ningún lado). El cableado de las URLs externas reales de Inventario y Viáticos es una tarea aparte (`FB-F6-02`). **No implementes el link externo real en esta tarea.**
