# FB-F1-08 — CI: instalación determinística de la CLI de Supabase

- **ID:** FB-F1-08
- **Fecha:** 19 de junio de 2026
- **Destino:** Claude Code
- **Propósito:** Que el job de integración instale la CLI de Supabase de forma determinística, sin depender de resolver "latest" contra la API de GitHub (que rate-limitea). Fix de infra de CI; no toca la app ni los tests.

## Contexto

FB-F1-07 migró la integración a un Supabase local real. El job fallaba en `supabase/setup-cli` al intentar resolver la última release con `version: latest` → la API de GitHub devolvía rate limit exceeded.

## Cambios implementados

### (1) Versión pineada de la CLI (fix principal)

**`.github/workflows/ci.yml`** — step `Setup Supabase CLI`:
```yaml
# Antes:
version: latest

# Después:
version: 2.75.0
```

`version: 2.75.0` corresponde a la versión instalada en el entorno de desarrollo local (verificada con `supabase --version`). Con una versión concreta, `supabase/setup-cli` puede construir la URL de descarga directamente sin llamar a la API de GitHub para resolver "latest".

### (2) GITHUB_TOKEN como respaldo

**`.github/workflows/ci.yml`** — mismo step:
```yaml
env:
  GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Aunque la versión pineada hace innecesaria la resolución de "latest", `GITHUB_TOKEN` eleva el límite de cualquier llamada residual a la API de 60 req/h (anónimo) a 5000 req/h (autenticado). El secreto está disponible por defecto en todos los repositorios de GitHub Actions; no requiere configuración adicional.

### (3) Versiones de actions (no bloqueante)

`actions/checkout@v4` y `actions/setup-node@v4` se conservan. Ambas referencias `@v4` apuntan automáticamente al último patch de la major 4 (que internamente usa Node.js 20). El warning de deprecación de Node.js 20 en el runner interno de las actions se eliminaría actualizando a `@v5` cuando esa major esté disponible y estable; es un ajuste cosmético, no un error.

## Archivos modificados

| Archivo | Cambio |
|---|---|
| `.github/workflows/ci.yml` | `version: latest` → `version: 2.75.0` + `GITHUB_TOKEN` |
| `docs/prompts/FB-F1-08.md` | Este archivo |

## Resultado esperado

El step `Setup Supabase CLI` descarga la versión `2.75.0` directamente, sin llamadas a la API de GitHub. Si hay alguna llamada residual, va autenticada con `GITHUB_TOKEN`. El job llega a `supabase start`, aplica las migraciones y ejecuta la suite de integración.
